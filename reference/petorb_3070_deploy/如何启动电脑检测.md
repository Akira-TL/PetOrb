# GO 3S 传到电脑检测 — 启动说明

相机（GO 3S）→ 手机 Demo（Wi‑Fi 预览）→ USB/adb → 本机 YOLO。

## 每次开检测：按这个顺序

### 1. 线先插好

- 手机 USB 插这台电脑，打开 **USB 调试**
- GO 3S 用 **Wi‑Fi** 连手机（不要只连蓝牙，蓝牙没有预览）

### 2. 电脑开服务

在资源管理器进入：

`F:\work\petorb_3070_deploy`

对 `scripts\start_pc_detect.ps1` **右键 → 使用 PowerShell 运行**
或在该目录的 PowerShell 里执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_pc_detect.ps1
```

等到窗口出现这两行，就成功了，**不要关这个窗口**：

```
adb reverse tcp:8080 tcp:8080 OK
listen 127.0.0.1:8080
waiting for frames on http://127.0.0.1:8080/frame ...
```

脚本会：找到 adb、做 `adb reverse tcp:8080`、用 conda 环境 `diffir2vr` 启动 `scripts\pc_detect_server.py`。

### 3. 手机 App

1. 打开已安装的 **Insta360 Demo**
2. 用 **Wi‑Fi** 连上 GO 3S
3. 进 **预览**，等到能看到实时画面
4. 点 **传到电脑检测**

按钮变成「停止传到电脑」、状态变成「正在发送预览帧」就对了。

电脑窗口会刷类似：

`boxes=…  detect=…ms  frames=…`

并弹出画面窗口（标题 `GO3S YOLO`）。按 `q` 只关画面窗口；要停整套服务看下面。

## 怎么停

1. 手机上点 **停止传到电脑**
2. 电脑那个 PowerShell 窗口里按 `Ctrl+C`，或直接关掉窗口

下次再用，从第 1 步重新来。拔过 USB 或重启过手机，必须重新跑一遍脚本（`adb reverse` 会丢）。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 脚本写 `adb reverse not ready` | USB 调试没开、换了线、或手机上点了「仅充电」。插好后再跑脚本 |
| 手机提示「连不上电脑」 | 电脑服务窗口还在、USB 还插着，再跑一次脚本，然后重新点「传到电脑检测」 |
| 提示「请等预览出画后再传」 | 必须先看到相机画面。确认相机是 Wi‑Fi/USB，不是仅蓝牙 |
| `adb devices` 是空的 | 手机通知栏允许这台电脑调试 |
| 没有检测窗口 | 脚本默认会弹出 `GO3S YOLO`。若自己加了 `--no-show` 就不会弹 |
