# PetOrb 比赛 Web 界面 — 启动说明

旧的 OpenCV 检测框还在，按 `如何启动电脑检测.md` 跑 `scripts\start_pc_detect.ps1` 即可，那套代码没改。

两套不要同时开（都占 `8080`）。要比赛网页，用下面这一套。

## 启动比赛页

1. 手机 USB 插电脑，打开 USB 调试；GO 3S 用 Wi‑Fi 连手机
2. 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_pc_detect_web.ps1
```

3. 等到 `listen 127.0.0.1:8080` 后，打开两个地址（不要关服务窗口）：
   - 技术端 **http://127.0.0.1:8080**
   - 用户端 **http://127.0.0.1:8081**
4. 手机 Demo 预览出画后，点 **传到电脑检测**

技术端左侧是最新预览 + OBB。右侧是 AI 帧、AI FPS、框、风险、判断、就医建议。
用户端采用 React + Vite 页面，实时显示牙龈相关区域 / 牙结石置信度与风险提示；回放里是检测后的带框图。修改 `web\user-app` 后运行 `pnpm build`，生成 `web\user-dist`，再重启服务。宠物插画位置预留，预约医生仍为演示入口。页脚固定：

PetOrb 提供辅助风险观察，不构成医疗诊断。

当前手机 App 未改，送帧大约 8 FPS；技术页显示实际接收和处理 FPS。要停：网页可关，PowerShell 里 `Ctrl+C`。
